## 🕹️ 核心游戏特性一览

1. **单局短平快（16 回合，约 15 分钟）**：
   * 🌸 春季（6 回合）：育苗培土，平稳起步
   * ☀️ 夏季（6 回合）：伏旱蚜虫，考验取舍
   * 🍂 秋季（4 回合）：抢收变现，秋末完税
2. **三档难度体系**：
   * 🌿 悠闲模式（税金 8🪙，通关率 ~97%，轻度科普）
   * ⚖️ 普通模式（税金 12🪙，通关率 ~57%，标准策略）
   * 🔥 困难模式（税金 16🪙，通关率 ~20%，硬核求存）
3. **自留种双轨循环**：
   * 收获时二选一：【💰 变现缴税】或【🌾 选优留种扩产】，摆脱无种可用的死循环。
4. **年终死因精准诊断**：
   * 失败不留遗憾，系统根据对局记录直击核心败因：【大旱绝收】、【虫灾失控】、【谷贱伤农】或【力不从心】。
