# 魔搭创空间部署步骤（Static SDK）

> 主推：`deploy/modelscope_static_full/` —— Godot 完整工程导出的网页版（约 48MB）
> 备用：`deploy/modelscope_static/` —— 单文件 Web 原型（46KB，加载快，但不是完整工程）
> 适用：AI+∞ 开发者创作大赛作品链接

---

## 一、两套部署包

| 包 | 内容 | 体积 | 适用 |
|---|---|---|---|
| `deploy/modelscope_static_full/` | `index.html` + `.js` + `.wasm` + `.pck` + 图标 | 约 48MB | **正式提交**，完整工程 |
| `deploy/modelscope_static/` | 单文件 `index.html` | 46KB | 网络/空间受限时备用 |

完整包由 Godot 3.5.3 导出（HTML5 / GLES2），已排除 `_devtest` 测试场景。

---

## 二、本地自检（部署前必须做）

### 2.1 启动本地服务

```powershell
cd D:\aigame\deploy\modelscope_static_full
python -m http.server 8766
```

浏览器打开 `http://127.0.0.1:8766/`。

> 不能直接双击 `index.html`：`.wasm` 必须通过 HTTP 提供，双击会停在加载页。

### 2.2 检查项

- [ ] 加载后出现主菜单「田间风云」
- [ ] 能点「开始游戏」进入开场/对局
- [ ] 能切换品级、出牌、结束回合
- [ ] F12 Console 无 404（尤其 `index.pck`、`index.wasm`）
- [ ] 检查 `.wasm` 的 Content-Type 为 `application/wasm`

自检完成后 `Ctrl+C` 关闭服务。

## 三、网页上传（推荐）

1. 登录 [modelscope.cn](https://www.modelscope.cn)，点右上角头像旁 **＋ → 创建创空间**。
2. 填写：
   - **空间名**：英文小写 + 连字符，例如 `field-chronicles`
   - **可见性**：`Public`
   - 简介：`卡牌种田 × 二十四候 × 五档官品`
3. 进入空仓库文件页。
4. 把 `deploy/modelscope_static_full` **文件夹整体拖入**（8 个文件必须一起传，缺 `.pck` 会白屏）。
5. 提交信息：`init: full web build`，确认上传（约 48MB，视网络 1–5 分钟）。
6. 上传完成后按引导选择 **SDK = Static**，入口 `index.html`，确认部署。
7. 等待状态变为 **Running**（Static 通常 30 秒–1 分钟）。
8. 在「应用」页完整试玩一局，复制 URL：
   `https://www.modelscope.cn/studios/<用户名>/field-chronicles`

## 四、Git 上传（可选，适合频繁更新）

```powershell
git lfs install

# 令牌在 https://modelscope.cn/my/myaccesstoken 获取
git clone https://oauth2:<YOUR_TOKEN>@www.modelscope.cn/<用户名>/field-chronicles.git

Copy-Item D:\aigame\deploy\modelscope_static_full\* .\field-chronicles\ -Recurse -Force

cd .\field-chronicles
git add .
git commit -m "init: full web build"
git push
```

推送后在创空间页面重新部署，等待 Running。

## 六、重新导出（改完工程后）

导出模板已安装（Godot 3.5.3，路径 `%APPDATA%\Godot\templates\3.5.3.stable\`）。重新导出：

```powershell
& "D:\gobot\Godot_v3.5.3\Godot_v3.5.3-stable_win64.exe" `
  --path "D:\aigame\GameIame" `
  --export "HTML5" "D:\aigame\deploy\modelscope_static_full\index.html"
```

更新创空间：把新的 8 个文件重新拖入覆盖，或 Git commit/push。

## 七、常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 停在加载页/白屏 | 只传了 `index.html` | 确认 `.js/.wasm/.pck` 都已上传 |
| 控制台报 wasm MIME 错误 | 静态托管未把 `.wasm` 标为 `application/wasm` | 换用备用单文件包；或向平台反馈；本地自检可先用 `python -m http.server` 对照 |
| 首次加载很慢 | 完整包约 48MB | 正常；后续有缓存会快 |
| 页面打开但画面空白 | 浏览器禁用了 WebGL | 换 Chrome/Edge，开启硬件加速 |
| 改了工程但线上没变 | 未重新导出或浏览器缓存 | 重新导出 + 覆盖上传 + Ctrl+F5 |
| Git push 要认证 | 未用访问令牌 | 用 `oauth2:<TOKEN>` 克隆 |
