# 《田间风云》开场动画重构方案

> 目标：移除飘雪，重做与「二十四候 / 继承荒田 / 卷轴卡组」世界观一致的开场
> 约束：Godot 3.5.3 / GLES2 / Windows + HTML5；复用现有美术；首屏 12~15 秒；必须可跳过
> 结论：推荐「农书墨痕 → 灯下成牌」的混合方案（方案 A+B）

---

## 一、为什么现在的开场不对

| 问题 | 具体表现 | 影响 |
| :--- | :--- | :--- |
| 飘雪定错了季节 | 雪在游戏里属于「冬藏」，开场却发生在春耕前 | 玩家第一印象是冬天，与"地荒了三年，准备重新开耕"的文案冲突 |
| 元素比例失衡 | 树、石、卷轴尺寸不统一，底部靠字幕条压住空场 | 画面像素材拼贴，缺少"一幅完整场景"的说服力 |
| 叙事靠字幕 | 四幕主要靠四句话推进，画面只是背景板 | 玩家记不住"继承农场—发现卷轴—接过卡组"的因果 |
| 缺少玩法预告 | 卡牌只在第三幕短暂出现 | 开场没有告诉玩家"这是一款卡牌种田游戏" |

本次重构的核心：**让画面承担叙事，字幕只做一句注解；用"农书 + 卡牌"把世界观和玩法一次讲清。**

---

## 二、世界观与文案对齐

保留的核心立意：

1. 你继承了一座荒废的农场
2. 石堆下压着前任农夫留下的农书/卷轴与卡组
3. 二十四候、四季轮转，农事从零学起

新开场的世界观锚点：

- **农书**代表"经验与传承"，也是二十四候的知识载体
- **卡牌**代表"农事本身"，四季各有一张，直接对应玩法
- **荒田**代表"起点"，用墨线、晨雾、风与尘土表达，而不是雪
- 文案从"描述环境"改为"描述动作"，每句话都对应一个画面动作

推荐文案（与动作一一对应）：

| 幕 | 文案 | 对应动作 |
| :--- | :--- | :--- |
| 1 | 「地荒了三年，草比人高。」 | 墨线自下而上勾出田垄，野草随风伏倒 |
| 2 | 「石头下压着一本旧农书。」 | 镜头下移石堆，尘土扬起，农书/卷轴展开 |
| 3 | 「二十四候，被他写成了二十四张牌。」 | 书页翻动，四张季节卡依次浮起、成弧 |
| 4 | 「今年，换你来打。」 | 卡牌收束成牌组，镜头推入卡面，墨迹转场进游戏 |

## 三、行业参考案例（5 个）

| # | 案例 | 类型/年代 | 实现方式 | 视觉特点 | 可复用价值 |
| :-: | :--- | :--- | :--- | :--- | :--- |
| 1 | **Pentiment**（Obsidian, 2022） | 手抄本叙事 RPG | 官方说明采用 limited frame animation，把角色与环境做成"书页里的木刻/绘画"；镜头在书页构图内移动 | 16 世纪手抄本、木刻线条、有限帧抖动 | **农书/卷轴分镜**：画面本身是"被翻开的书页"，与我们的卷轴设定天然契合 |
| 2 | **Inscryption**（Daniel Mullins, 2021） | 卡牌 Roguelike | 第一人称坐在牌桌前，卡牌由手递入、翻面、落桌；镜头贴近桌面 | 昏暗木屋、烛光、卡牌特写 | **灯下牌桌**：卡牌作为叙事主体，落桌/翻面即节奏 |
| 3 | **GRIS**（Nomada Studio, 2018） | 水彩平台 | 全手绘逐帧动画，水彩色块作为场景与转场；大量留白与色彩渐变 | 水彩晕染、无声叙事、情绪转场 | **色彩/雾气的过渡**：用色块与雾气替代雪，做季节与情绪的软过渡 |
| 4 | **Card Shark**（Nerial, 2022） | 卡牌叙事 | Unity 案例：单版画（monoprint）分层 2D 资产，逐层导入与优化；角色近"定格动画" | 版画质感、厚涂笔触、桌面特写 | **版画/纸面质感**：证明分层 2D + 轻动效也能做出高级感 |
| 5 | **Cultist Simulator**（Weather Factory, 2018） | 卡牌叙事 | 卡片即 UI（diegetic interface），桌面上的卡牌承担全部信息与操作 | 桌面、烛光、卡牌拼贴 | **卡牌当界面**：开场可直接把"农书/卡组"作为可读对象 |

补充：Hades 的漫画分镜式演出（Studio Grackle 制作的动画预告）也验证了"分格 + 硬切 + 字幕"的有效性，但成本偏高，本次不作为主方案。

**共性结论**：成熟开场不靠复杂特效，而靠「一个明确的叙事物件（书/桌/卡）+ 有限但精准的镜头运动 + 一个统一的材质语言（纸/版画/水彩）」。这正好符合我们的资源条件。

## 四、候选方案对比

### 方案 A｜农书墨痕（Pentiment / Card Shark 路线）

- **画面**：镜头俯视一本摊开的旧农书；墨线在纸面上自行勾出田垄、石堆、草叶；书页翻动时，四季卡从纸面浮起
- **动效**：墨线生长（Line2D + 抖动）、纸页翻动（scale.x 翻转 + 高光）、卡牌弧线浮起、晨雾横向漂移
- **时长**：14~15 秒，四幕
- **转场**：最后一页翻起时，墨迹从纸面扩散覆盖全屏 → 进入游戏
- **技术**：现有 `scroll.svg` + `ink_wipe.shader` + `Line2D` + Tween；无需新增大图
- **优点**：与"卷轴/农书"设定最贴合；材质统一；成本低；天然解释"二十四候"的来源
- **缺点**：静态感偏强，需要靠镜头与翻页制造节奏；墨线绘制需要调参

### 方案 B｜灯下牌桌（Inscryption / Cultist Simulator 路线）

- **画面**：暖色油灯下的一张木桌；一双手（或前景遮挡）把四张季节卡依次放到桌面；卡面特写后翻面，露出"春苗/夏虫/秋收/冬税"意象
- **动效**：卡牌落桌的回弹、翻面、轻微视差；灯焰摇曳；桌面阴影
- **时长**：12~14 秒
- **转场**：最后一张卡推向镜头，卡面铺满屏幕 → 墨迹转场
- **技术**：现有卡面 + 一张木桌底图（可用程序化木纹或现有素材调色）；Tween + 2D 光影；无粒子或极少
- **优点**：最直接预告"卡牌玩法"；镜头语言简单；沉浸感强
- **缺点**：与"荒田/继承农场"的世界观联系较弱；需要一张桌面底图；容易做成"卡牌游戏通用开场"

### 方案 C｜版画分镜（Hades / Card Shark 路线）

- **画面**：四格木刻版画，硬切推进：荒田 → 石堆 → 农书 → 卡组；字幕作为版画上的题记
- **动效**：分格入画、纸面抖动、墨迹擦除；镜头在格与格之间硬切
- **时长**：10~12 秒
- **转场**：最后一格墨迹扩散 → 游戏
- **技术**：需要 4 张版画风格分镜图（可基于现有素材重绘/滤镜），成本最高
- **优点**：风格强烈、节奏干脆、信息密度高
- **缺点**：新美术成本高；与现有像素/矢量素材的融合风险大；容易"预告片化"

### 对比评分

评分 1~5，成本项 5 = 最省。

| 维度 | A 农书墨痕 | B 灯下牌桌 | C 版画分镜 |
| :--- | :-: | :-: | :-: |
| 世界观契合 | 5 | 4 | 4 |
| 玩法预告 | 4 | 5 | 3 |
| 氛围营造 | 5 | 4 | 5 |
| 资源成本 | 5 | 4 | 2 |
| 技术风险（越低越高分） | 5 | 4 | 3 |
| 与现有素材融合 | 5 | 4 | 2 |
| **综合** | **29** | **25** | **19** |

**结论：以 A 为主体，第三/四幕借用 B 的"卡牌落桌与卡面推近"作为玩法钩子。** 这样既保留"农书/卷轴"的世界观，又在结尾明确告诉玩家"这是一副牌"。

## 五、推荐方案：农书墨痕 → 灯下成牌（A+B）

### 5.1 分幕脚本

| 幕 | 时长 | 画面与动效 | 文案 | 交互 |
| :--- | :-: | :--- | :--- | :--- |
| 1 荒田 | 3.5s | 俯视纸面；墨线自下而上勾出田垄，草叶轻摆；晨雾从左向右缓慢漂移 | 地荒了三年，草比人高。 | 点击推进 |
| 2 石下 | 4.0s | 镜头下移/推近石堆；尘土 12~18 颗扬起；农书从石下露出并展开 | 石头下压着一本旧农书。 | 点击推进 |
| 3 成牌 | 4.5s | 书页翻动 1 次；四张季节卡从纸面浮起，成弧排列并轻微错落 | 二十四候，被他写成了二十四张牌。 | 点击推进 |
| 4 接牌 | 3.0s | 四张卡收束成牌组；最上一张推向镜头直到铺满；墨迹覆盖 | 今年，换你来打。 | 自动结束 |

总时长约 15 秒。点击/空格推进一幕；长按 0.6 秒或 ESC 立即跳过；保留主菜单「回访时播放极简开场」开关。

### 5.2 视觉与动效规范

- **材质统一**：纸面、墨线、卡牌三者同属"纸/印刷"语言；不使用飘雪、不使用全屏后处理
- **晨雾替代雪**：两层半透明雾（同一贴图不同速度/透明度），横向漂移速度 6~10 px/s，避免"天气"感
- **墨线**：`Line2D` 从 0 到目标点数逐帧追加，配合轻微随机抖动；仅在幕 1 使用
- **翻页**：`scroll/paper` 节点 `rect_scale.x` 从 1→0→1，切换前后两张纸面；峰值时叠加白色高光
- **卡牌弧线**：四张卡按 −6°/−2°/2°/6° 排列，Y 抬升 20px；浮起使用 `TRANS_CUBIC/EASE_OUT` 0.7s，错峰 0.12s
- **镜头**：仅用 `Stage` 的 position/scale 变化，位移幅度 ≤ 20%，避免眩晕
- **无雪**：删除 `Snow` 粒子与所有雪贴图引用；改为尘土 + 雾

### 5.3 文案与画面联动规则

1. 字幕只在对应动作**完成后 0.2 秒**淡入，避免"先读字后看画"
2. 每幕只允许一句、不超过 18 字
3. 字幕位置固定在底部安全区，不遮挡石堆与卡牌
4. 幕 3 的"二十四候"与卡牌数量形成呼应：画面只展示 4 张季节卡，文案点出"二十四候"，把细节留给游戏

### 5.4 技术实现

| 模块 | 实现 | 说明 |
| :--- | :--- | :--- |
| 纸面/农书 | 复用 `tutorial/scroll.svg`，调色为旧纸；必要时叠一层程序化纸纹 | 无新增大图 |
| 墨线 | `Line2D` + `_process` 追加点 + 随机抖动 | 不依赖贴图 |
| 翻页 | `rect_scale.x` 翻转 + 高光 `ColorRect` 闪烁 | 3.5 原生能力 |
| 卡牌 | 复用 `cards/card_seeds|water|attak|tank` | 与游戏内一致 |
| 雾/尘 | `CPUParticles2D`（尘 ≤ 18） + 2 层 ScrollSprite 雾 | GLES2 友好 |
| 转场 | 现有 `shaders/ink_wipe.shader`，最后一幕 `progress 0→1` | 已验证可用 |
| 时序 | `Tween` 驱动镜头/卡牌，`AnimationPlayer` 负责定值翻页与字模 | 与现有工程一致 |

**性能预算**：静态贴图 ≤ 12 张、粒子 ≤ 18、无全屏 Shader 采样、无视频；1080×800 / GLES2 目标 60FPS，HTML5 导出需实测。

**资源成本**：0 张新大图；新增 1 个墨线脚本逻辑、1 个雾层复用、1 次纸面调色；改动集中在 `Intro.tscn` / `Intro.gd`。

### 5.5 验收标准

- 完整播放 14~16 秒，四幕节奏清晰，无飘雪
- 任意时刻点击推进、长按/ESC 跳过、回访开关生效
- 结束后经墨迹转场进入 `Game`，第一候横幅正常
- 1080×800 与任意窗口尺寸下构图等比居中，无裁切
- `autotest` / `flowtest` 无脚本错误；HTML5 导出可播放

## 六、风险与回退

| 风险 | 对策 |
| :--- | :--- |
| 墨线看起来像"线条动画"而非手绘 | 给 `Line2D` 加宽度抖动与两段速度（起笔快、收笔慢），并叠一层纸纹 |
| 翻页在 GLES2 下出现拉伸伪影 | 翻页用 `rect_scale` 而非 Shader；失败则退化为淡入淡出 |
| 雾层削弱文字可读性 | 雾只放在场景层，字幕区不加雾；字幕底板保持 0.55 不透明度 |
| 卡牌浮起遮挡书页文字 | 书页在幕 3 只作为背景，不承载正文 |
| 开场过长 | 保留点击推进与跳过；回访开关继续有效 |
