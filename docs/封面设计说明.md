# 《田间风云》封面设计说明

## 一、设计概念

「一亩田，二十四候，一场风云」。

封面用三层叙事把核心玩法一次讲清：

| 层 | 画面 | 对应玩法 |
|---|---|---|
| 天 | 暮色、落日、远山 | 二十四候的时令流转与岁赋压力 |
| 人 | 戴斗笠的老农立于稻浪中央 | 玩家本人；耕作、浇水、护苗 |
| 牌 | 环绕老农的发光卡牌 | 卡牌驱动；种植/灌溉/除虫/防御 |
| 敌 | 画面左右边缘的甲虫剪影 | 虫害与虫王；不抢主体但形成压迫感 |

金稻、夕阳与斗笠构成三角构图，视线先落在标题，再落到人物，最后扫到两侧虫影，符合 3 秒内读完信息的商店封面逻辑。

## 二、配色

| 名称 | 色值 | 用途 |
|---|---|---|
| 墨青 | `#1C2620` | 夜空、标题底衬、暗角 |
| 暮金 | `#E3B866` | 落日、副标题、描金边框 |
| 稻金 | `#D9A441` | 前景稻浪、卡牌暖光 |
| 土褐 | `#5A3E28` | 远山、田埂、画面过渡 |
| 朱印 | `#B33A2F` | 标题右侧「丰」印，唯一高饱和点缀 |
| 宣纸 | `#F2E8D0` | 标语文字、留白文字 |

整体控制在「墨青 + 金 + 一点朱红」，与游戏内主菜单、开场卷轴一致；朱印是唯一高饱和色，保证缩略图下的记忆点。

## 三、版式与安全区

- 横版：标题占上 28%，人物居中偏下，顶部 120px 与底部 100px 为文字安全区。
- 竖版：标题在上 18%，人物与院落居中，底部稻浪留白，适配手机商店竖图。
- 小尺寸：只保留「标题 + 朱印 + 人物剪影」，删去副标题和标语，避免糊成一团。

## 五、分层源文件

主源文件：`art/cover/cover_source.ora`（OpenRaster，Krita / GIMP 可直接打开）。

图层（自下而上）：

| 图层 | 内容 | 可调项 |
|---|---|---|
| `背景` | AI 生成主视觉（已裁掉右下角水印） | 替换整张插画 |
| `氛围光` | 顶部压暗 + 底部暗角渐变 | 调整标题区对比度 |
| `标题` | 从 `ui/splash_cn.png` 提取的金属字组 + 朱印 | 位置、缩放、透明度 |
| `副标题` | 「二十四候 · 五档官品 · 卡牌种田」 | 文案、字号、字距 |
| `描金边框` | 内嵌 2px 金色细线 | 颜色、内边距 |

同名分层 PNG 也单独保存在 `art/cover/layers/`，方便在不支持 ORA 的工具里重组。

## 六、可复现构建

```powershell
& "C:\Users\LENOVO\AppData\Local\Programs\Python\Python313\python.exe" D:\aigame\art\cover\build_cover.py
```

- 依赖：Pillow
- 输入：`art/cover/raw/keyart_landscape.jpg`、`keyart_portrait.jpg`、`GameIame/ui/splash_cn.png`
- 输出：`exports/` 全部尺寸、`layers/` 分层、`cover_source.ora`
- 修改标题文案或位置，只需改脚本里的 `compose_landscape` 调用参数

## 七、素材与版权说明

- 背景插画为 AI 生成（text-to-image），无第三方素材。
- 标题字组来自项目自有 `ui/splash_cn.png`，与游戏内品牌一致。
- 副标题字体为项目自带 `fonts/SimHei.ttf`。
- 生成图右下角平台水印已在构建时裁除。
