# 田间风云 · 二十四候（Web 试玩版）

卡牌驱动的种田经营小游戏：24 候完成一年耕作，在虫害、旱情与岁赋之间活下来。

## 玩法

- 每候 3 点体力、抽 5 张手牌
- 种下作物后浇水推进生长，成熟后收获：选一张卡，或卖粮换金币
- 虫害会啃食作物；用攻击/防御卡护苗
- 第 24 候结束按存银缴纳岁赋；种出「百年月华·金稻」可达成传奇胜利

## 操作

- 点击手牌 → 点击田地/目标 → 打出
- 右下角「结束回合」推进时令
- 顶部下拉框切换品级（九品 → 一品）
