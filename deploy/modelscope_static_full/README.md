# 田间风云 · 完整工程 Web 版

> 由 Godot 3.5.3 完整工程导出（HTML5 / GLES2），非简化原型。

## 玩法

- 24 候单局，每候 3 点体力、抽 5 张手牌
- 种植 → 浇水 → 除虫/防护 → 成熟收获（选卡或卖粮）
- 五档官品：税 + 虫 + 旱三维差异，第 24 候按存银完税
- 隐藏结局：种出「百年月华·金稻」直接传奇胜利

## 操作

- 点击手牌 → 点击目标田地/作物打出
- 右下角「结束回合」推进时令
- 主菜单可切换品级、跳过教程、调节音量

## 文件说明

| 文件 | 用途 |
|---|---|
| `index.html` | 页面入口 |
| `index.js` | 引擎加载器 |
| `index.wasm` | Godot 运行时 |
| `index.pck` | 游戏资源包（约 35MB） |
| `index.png` / `index.icon.png` | 页面图标 |

> 部署时必须**整个文件夹一起上传**，缺少 `.pck` 或 `.wasm` 会停在加载页。
